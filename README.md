# AutoMob-Mechanic 🚗

A responsive automobile service website designed to help customers explore car maintenance services and book appointments conveniently.

## 📌 About the Project

AutoMob-Mechanic is a front-end web development project that provides information about automobile services, including preventive maintenance, body repair, and car care. Users can explore services, submit booking details, and view a booking confirmation page.

## ✨ Features

- **Home Page:** Introduction to AutoMob-Mechanic and its benefits.
- **Services Page:** Overview of available automobile services.
- **Preventive Maintenance:** Information about vehicle inspections, oil checks, brakes, tyres, and battery maintenance.
- **Body Repair:** Details about dent repair, scratches, painting, and exterior damage.
- **Car Care:** Information about interior cleaning, exterior washing, and car detailing.
- **Service Booking:** Form to enter customer and vehicle details and select a service.
- **Appointment Scheduling:** Form to select a preferred date and time.
- **Booking Confirmation:** Confirmation page displayed after submitting a form.
- **Responsive Layout:** CSS media queries help adapt the layout to smaller screens.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/arunjaiswal8726-lang/automob.git
   ```

2. Open the project folder:

   ```bash
   cd automob
   ```

3. Open `home.html` in your browser.

4. Alternatively, open the folder in Visual Studio Code and use the **Live Server** extension.

## 📖 How to Use

1. Open the home page.
2. Navigate to the Services page.
3. Explore the available automobile services.
4. Open the booking or appointment form.
5. Enter the requested customer and vehicle details.
6. Submit the form to view the booking confirmation page.

## 🎯 Project Objective

The objective of this project is to demonstrate front-end web development skills through a multi-page automobile service website, including navigation, form elements, reusable CSS styling, and responsive layouts.
